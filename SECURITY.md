# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: **Security → Report a vulnerability** on this repository, or email `info@andeanscapes.com`.

Include the affected URL or file, steps to reproduce, and the impact. We aim to acknowledge reports within 5 business days.

## Scope

- Public website and its Cloudflare Worker
- Build and deploy tooling in this repository

Feed content, bookings and payments are operated by Andean Scapes; report issues with them through the same channels.
